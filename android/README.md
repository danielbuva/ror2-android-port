# Source-owned laboratory harness

These scripts are original diagnostic/build tooling. `./dev prototype` stages them into ignored work/lab-project, imports one utility DLL from the user's installation, and converts one local mesh. No game DLL, mesh, bank or reconstructed source belongs here.

The harness is not a RoR2 player. It proves IL2CPP preservation of a utility API, Android bundle rendering, storage paths and collection. Runtime diagnostics are development-only by distribution policy: do not ship this project as an end-user release without a separate release configuration.
