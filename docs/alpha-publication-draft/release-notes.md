original input and follow [approved key recovery and rollback instructions].

## Report a problem

Share the release version, phone model, Android version and steps to reproduce.
Use [GitHub Issues](https://github.com/danielbuva/ror2-android-port/issues)
or review the in-app feedback draft before opening it in a browser. Opening
the draft sends its text to GitHub. Submitting the issue is a separate action.
Keep raw logs, captures, game files, generated packages, saves, account
details and signing material private.
