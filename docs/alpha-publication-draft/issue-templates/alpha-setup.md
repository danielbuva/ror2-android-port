GitHub issues are public. Share reviewed text only. Keep raw logs, screenshots,
game files, generated APKs, saves, serials, private paths, account details and
signing material private.

**Versions and device**

Port release and installer versions, PC game version if shown, phone model
and Android version.

**Where it stopped**

Folder or ZIP import, verification, build, install, first launch, Check for
updates, rebuild or rollback. For updates, give both port versions and
describe whether existing progress and settings still appear.

**Steps to reproduce**

List the shortest steps and say whether a retry changes the result.

**Expected and actual result**

Describe what you expected and summarize the on-screen error in your own words.
