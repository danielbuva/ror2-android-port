# Draft alpha announcement

Draft for the channel and timing the owner approves.

The first owner-built Android alpha of the Risk of Rain 2 port is available.
If you own the PC game, you can use your game files and the alpha tools to
build an offline Android version on your phone.

This alpha covers [device-verified survivors, stages and controls]. Check the
release notes for tested devices, supported PC inputs, storage needs and
known limits before starting. Progress is stored locally on Android. Steam
sign-in, online multiplayer and Steam Cloud are unavailable.

[Approved release and setup guide]

If something goes wrong, open a GitHub issue with the release version,
device model, Android version and steps to reproduce. Keep raw logs,
screenshots, game files, generated packages and account details private.
