# Draft alpha publication package

For maintainer review. The [publication policy](../ALPHA_POLICY.md#distribution-and-feedback)
requires separate owner approval for the release, announcement, repository
settings and issue templates.

- [Release notes](release-notes.md) for GitHub Releases.
- [Announcement](announcement.md) for the channel the owner approves.
- [Repository settings and publication steps](repository-settings.md) for the
  maintainer.
- Draft issue templates for [setup and updates](issue-templates/alpha-setup.md)
  and [gameplay and controls](issue-templates/alpha-gameplay.md), with the
  [template chooser configuration](issue-templates/config.yml).

The bracketed fields need values from the approved candidate and its device
receipts. The [alpha checklist](../public-alpha.md) tracks release acceptance.
The issue drafts live here for review. GitHub reads active issue templates
from `.github/ISSUE_TEMPLATE/` on the default branch.
