# Repository branding

These graphics identify this unofficial Android conversion project. They are
promotional images for the repository, not launcher or runtime assets.

- [Banner PNG](ror2-android-banner.png) — 1920 × 640.
- [Download the icon PNG](ror2-android-icon.png) — 768 × 768.

[promotional artwork](https://cdn.akamai.steamstatic.com/steam/apps/632360/library_hero.jpg)
and [original logo](https://cdn.akamai.steamstatic.com/steam/apps/632360/logo.png),
with additional project typography. The icon crops the same promotional artwork.
