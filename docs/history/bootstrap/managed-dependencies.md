# Managed code findings

VERIFIED: RoR2.dll is IL managed code, not an IL2CPP metadata shell. All 143 assemblies can be read through System.Reflection.Metadata; 143/143 project decompilations completed with ilspycmd 11.0.0.9375. The initial default-language pass produced 19,679 source files; RoR2 produced 3,851 files from 5,847 types because nested/compiler-generated types do not map one-to-one to source files. Successful decompilation does not mean successful recompilation.

The initial C# 14 source compile against installed references reported 11 unique accessibility/ambiguity errors. Feeding that output into a C# 9 compiler produced thousands of syntax errors from language mismatch. The workflow now requests CSharp9_0 explicitly; consult `work/experiments/recompile/result.json` for the corrected compiler result. Preserve both experiments; do not repair thousands of language-version artifacts by hand.

`managed.json` enumerates every assembly/version/reference, type, method signature, field signature, P/Invoke library and entry point, and external member reference. `seams.json` identifies unresolved assembly names and candidate Windows, reflection, emit, audio, input, networking and filesystem seams. `decompilation.json` counts unsafe keywords, decompiler diagnostics and source conditionals. These are static inventories, not complete reachability or whole-program unsafe verification. Missing references must be distinguished from intentionally supplied Unity editor/player assemblies. Original preprocessor branches eliminated by the Windows compiler cannot be recovered from this binary.

Full source reconstruction is not yet demonstrated necessary. AOT preservation of a simple assembly is a necessary but insufficient test for the hybrid. The full exported dependency closure was subsequently tested with a minimal Android scene. It fails in IL2CPP VTable construction for types mapped to Rewired_Core and Rewired_Windows. Next isolate the Rewired platform boundary; do not infer that source reconstruction of all gameplay is required.

Final static coverage: no unresolved assembly names among the 143 installed assemblies; 2,286 type names are marked compiler-generated by the scanner heuristic. C#9 decompilation reports 23 invalid-IL/type diagnostic markers across the whole framework/game set and no decompiler-failure markers. RoR2 itself has zero such markers. Reflection.Emit member-reference candidates occur in framework assemblies; their presence is not proof game-reachable dynamic code generation.
