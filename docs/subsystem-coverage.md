# Coarse subsystem coverage

Coverage describes the current route, not a percentage of the complete game. Use **original** for unchanged shipped logic/data executing in its native contract, **recovered** for content/programs reconstructed from legitimate input, **adapted** for an explicit Android context/lifecycle/input boundary, **approximate fallback** for a known semantic or presentation difference, and **unavailable** for an unsupported capability. A definition in a catalog is not a working gameplay feature. Rows may have several classifications for different layers.
