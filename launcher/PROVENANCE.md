# Launcher asset provenance

`background.png` is the user-approved fourth revision of an AI-generated scene,
created with the built-in image tool for this launcher. Three official Steam
screenshots were visual style references for rock geometry, material patches,
vegetation and lighting: https://store.steampowered.com/app/632360/Risk_of_Rain_2/ .
Reference screenshots are not included. The output is not official artwork or
an actual game screenshot; no extracted models, textures or game files are added.
This record is provenance, not rights-holder clearance or a license to the game.

The public audit permits only this exact path and SHA-256, separately from the
two repository promotional graphics. Copies, altered bytes and any other PNG
remain denied. An update requires a new provenance review and pinned hash.
The demo shares this same file; no duplicate image exception is needed.

HTML, CSS and JavaScript are authored launcher UI. Typography uses locally
installed system fonts, with no font files. The game name appears as plain text;
game trademarks and rights remain with their respective owners. No endorsement
or affiliation is claimed. No music, game logo or proprietary runtime is included.
Public About intentionally omits this developer-facing provenance paragraph.
